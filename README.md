# Рамки

Мобильный помощник для учёбы первокурсника. Держит в рамках и не стыдит: календарь дедлайнов,
план дня с учётом дороги, пар и минимума сна, отработка тем и карточки. Работает как обычный сайт
на GitHub Pages, ставится на экран «Домой» iPhone и работает без интернета.

## Что внутри

- **Календарь** (главный экран): метки дедлайнов по цвету типа — КР, лаба, зачёт, сессия, сдача;
  перегруженные дни заштрихованы. Дедлайны добавляются вручную или вставкой текста.
- **День по часам**: серые блоки — сон, утренняя дорога (досыпаешь), пары, еда; цветные — учёба
  в электричке (карточки, теория), дома (задачи с тетрадью), повторение перед сном; отдельным
  цветом — игра, она стоит после учебных блоков и заканчивается за 30 минут до отбоя.
  «Собрать день» задаёт 3 вопроса кнопками, «Править день» меняет время за пару тапов.
- **Сборка плана** по правилам: ближайший дедлайн — первым, тяжёлое — дома вечером, лёгкое —
  в дороге. Сон не меньше минимума никогда. Если времени не хватает — честное предупреждение
  и варианты: сократить подготовку, без игры перед дедлайном, взять воскресенье, учиться
  в утренней дороге.
- **«Не успел»** у каждого блока — спокойно переносит и пересобирает остаток дня и ближайшие дни.
- **Догоняю**: отставание по предмету («отстаю на N дней» или «часов на догоняние») делится
  поровну по неделям до срока и идёт сразу после ближайших дедлайнов. Сейчас: физика
  и информатика — ~4 ч 25 мин за 3 недели, остальные — по 20–40 мин за 2 недели, история —
  с нуля, ~12,5 ч за 6 недель по темам докладов (каждая тема — один раз, отмеченная «готово»
  тема больше не повторяется). Меняется в «Настройках → Предметы».
- **Сегодня**: максимум 3 задачи с шагом «С чего начать», утренний и вечерний чек-ин в 2 тапа,
  привычки (Duolingo, зарядка), таймер 25/5, серия дней.
- **Горит**: ближайшие дедлайны, прогресс подготовки, что делать первым, незакрытые темы.
- **Темы**: конспект, банк заданий, отработка с проверкой и разбором, ошибки возвращаются,
  статус темы меняется по результатам. Карточки — слабые вопросы чаще.
- **Посещаемость**: счётчик пропусков по предметам, лимиты вводишь сам, важные пары подсвечены.
- **Данные** — в localStorage телефона, копия в файл раз в неделю (удобно — в Telegram «Избранное»).

## Как выложить на GitHub Pages

1. Залить файлы в ветку `main` репозитория.
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `main`, папка `/ (root)` → Save**.
3. Через минуту-две сайт будет по адресу `https://ermac999.github.io/PTU-MIREA/`.
4. На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».

## Настройки

- Все числа и правила планировщика — в **`js/config.js`** (объект `CONFIG` в начале файла):
  минимум сна, длина дороги, лимиты учёбы по дням, длительность игры, часы подготовки к событиям.
- Данные из опроса (режим недели, пары, предметы, дедлайны, примерные темы) — там же,
  в `DEFAULT_DATA`. Они попадают в приложение при первом запуске, дальше всё правится
  в «Настройках» и хранится на телефоне.
- **Мои предположения, которые стоит проверить**: отбой в четверг 23:30 и в пятницу 23:00,
  подъём в воскресенье 09:00, «иностранный язык = немецкий», начало сессии 1 декабря,
  КР — на практике по предмету в этот день. Всё меняется в «Настройках» или карточке события.

## Банк заданий

- Файл **`data/bank.json`**: задания (`tasks`) и карточки (`cards`). Сейчас там только примеры
  (`"example": true`), чтобы было на чём потренироваться. По истории — задания и карточки
  к темам докладов (`hist-t1` … `hist-t30`; темы 16–22 ждут названий со слайда 33).
- Добавлять свои проще в приложении: «Темы → Добавить задания текстом», формат:

  ```
  Предмет: Физика
  Тема: Кинематика
  Вопрос: Тело прошло 120 м за 20 с. Скорость, м/с?
  Ответ: 6
  Разбор: v = s / t
  ---
  Вопрос: …
  ```

  Несколько верных ответов — через `|`, варианты для выбора — строкой `Варианты: а | б | в`,
  допуск для чисел — `Точность: 0.1`.
- Через чат: присылаешь конспект, фото тетради или список вопросов — получаешь текст в этом
  формате и вставляешь.

## Разработка

```bash
npm test              # тесты логики: расписание, план, сон, отработка, разбор текста, .ics
npm run serve         # локальный сервер на http://localhost:8080
npm run build:preview # одностраничная сборка для превью (tools/build-preview.mjs)
```

Структура:

```
index.html, manifest.webmanifest, sw.js   страница, установка на «Домой», офлайн
css/app.css                               стили (светлая и тёмная тема)
js/config.js                              CONFIG и данные из опроса
js/util.js, schedule.js, planner.js       даты, структура дня, планировщик
js/practice.js, parse.js, ics.js          отработка и карточки, разбор текста, календарь .ics
js/store.js, bank.js, nav.js, ui.js       хранение, банк, переходы, элементы интерфейса
js/views/*.js                             экраны
data/bank.json                            банк заданий
docs/                                     напоминания и ИИ
tests/                                    тесты (node --test)
```

Шрифт заголовков — Playfair Display (SIL Open Font License, `fonts/OFL.txt`), лежит в папке
приложения и работает без интернета.
