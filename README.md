# Рамки

Мобильный помощник для учёбы первокурсника. Держит в рамках и не стыдит: календарь дедлайнов,
план дня с учётом дороги, пар и минимума сна, отработка тем и карточки. Работает как обычный сайт
на GitHub Pages, ставится на экран «Домой» iPhone и работает без интернета.

## Что внутри

- **Главная** (первый экран): четыре раздела — Календарь, Предметы, Развлечения (шахматы; КС — вечерний
  слот в плане), Проекты (твои артефакты из Claude — пока по ссылке на claude.ai, список — `js/portal.js`).
- **Шахматы** — «Дебютная тетрадь» перенесена на сайт: `modules/chess/` (страница, своя копия chess.js,
  база партий чемпионов `pro/*.json`, прогресс из облака артефакта в `seed.json` — переносится один раз).
  Кнопка «Стиль и доска»: 3 стиля приложения (Спираль, Клуб, Неон) плюс исходное «Золото» и 9 досок
  (Классика, Турнир, Лёд, Орех, Мрамор, Сакура, Графит, Неон, Океан), выбираются независимо.
- **Календарь** (главный экран): метки дедлайнов по цвету типа — КР, лаба, зачёт, сессия, сдача;
  перегруженные дни заштрихованы. Дедлайны добавляются вручную или вставкой текста.
- **День по часам**: серые блоки — сон, утренняя дорога (досыпаешь), пары, еда; цветные — учёба
  в электричке (карточки, теория), дома (задачи с тетрадью), повторение перед сном; отдельным
  цветом — игра, она стоит после учебных блоков и заканчивается за 30 минут до отбоя.
  «Собрать день» задаёт 3 вопроса кнопками, «Править день» меняет время за пару тапов.
- **Сборка плана** по правилам: ближайший дедлайн — первым, тяжёлое — дома вечером, лёгкое —
  в дороге. Сон не меньше минимума никогда. Если времени не хватает — честное предупреждение
  и варианты: сократить подготовку, без игры перед дедлайном, взять воскресенье, учиться
  в утренней дороге.
- **Лабы по физике**: лаба делается на паре, дома её доделывают — в плане один блок
  «досчитать расчёты и ответить на контрольные вопросы» (~1,5 ч), без подготовки к допуску.
- **Зал**: среда и суббота сразу после пар, воскресенье — утром после завтрака (дорога + тренировка ≈ 2,5 ч); ужин и учёба — после.
  Любой из трёх дней выключается в «Настройках → Игра и привычки», один день — в «Править день» → «Сегодня без зала».
  В остальные дни зала нет.
- **«Не успел»** у каждого блока — спокойно переносит и пересобирает остаток дня и ближайшие дни.
- **Догоняю**: отставание по предмету («отстаю на N дней» или «часов на догоняние») делится
  поровну по неделям до срока и идёт сразу после ближайших дедлайнов. Сейчас: физика
  и информатика — ~4 ч 25 мин за 3 недели, остальные — по 20–40 мин за 2 недели, история —
  с нуля, ~12,5 ч за 8 недель (до 11 декабря) по темам докладов (каждая тема — один раз, отмеченная «готово»
  тема больше не повторяется). Меняется в «Настройках → Предметы».
- **Сегодня**: максимум 3 задачи с шагом «С чего начать», утренний и вечерний чек-ин в 2 тапа,
  привычки (Duolingo, зарядка), таймер 25/5, серия дней.
- **Горит**: ближайшие дедлайны, прогресс подготовки, что делать первым, незакрытые темы.
- **Темы**: список предметов → страница предмета (темы, игры, догоняние) → тема: теория
  «кратко» или «подробно» (сама выбирает «кратко», если тема знакома или контрольная через
  1–2 дня), игры по теме, конспект, банк заданий, отработка с проверкой и разбором. Ошибки
  возвращаются, статус темы меняется по результатам. Карточки — слабые вопросы чаще.
- **Игры** (папка `modules/`), прогресс перенесён из Claude: «Кинематика на зачёт» — 15 уровней
  и финальная контрольная (Физика → Кинематика); «Бит за битом» — 8 модулей по практикам
  информатики. Открываются со страницы предмета, темы и из блоков плана («Игра →»).
- **«Спираль»** — игра семестра (плитка на главной): каждый предмет — мир-виток со своим цветом
  и темой, внутри его игры; общие звёзды и звание. Физика и информатика уже с играми, линал,
  матан, матлогика и история — «мир строится».
- **Информатика** — темы = 8 практик курса (количество информации, кодирование, ошибки,
  системы счисления, доп. код, вещественные числа), у каждой теория и номера задач по уровням игры.
- **Линал** — темы = 6 практик по тетради (матрицы, определители, Крамер и обратная матрица,
  матричные уравнения, ранг и Гаусс, векторы), теория на примерах из практик с пометками,
  где в тетради ошибка; 44 задачи с проверкой и колода «Линал: по твоим практикам».
- **Темы контрольной**: в карточке события отмечаешь, что входит, — подготовка идёт по этим
  темам по порядку, а в блоках плана появляется «Теория →».
- **Посещаемость**: счётчик пропусков по предметам, лимиты вводишь сам, важные пары подсвечены.
- **Данные** — в localStorage телефона, копия в файл раз в неделю (удобно — в Telegram «Избранное»).

## Как выложить на GitHub Pages

1. Залить файлы в ветку `main` репозитория.
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `main`, папка `/ (root)` → Save**.
3. Через минуту-две сайт будет по адресу `https://ermac999.github.io/PTU-MIREA/`.
4. На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».

## Настройки

- Все числа и правила планировщика — в **`js/config.js`** (объект `CONFIG` в начале файла):
  минимум сна, длина дороги, лимиты учёбы по дням, длительность игры, часы подготовки к событиям.
- Данные из опроса (режим недели, пары, предметы, дедлайны, примерные темы) — там же,
  в `DEFAULT_DATA`. Они попадают в приложение при первом запуске, дальше всё правится
  в «Настройках» и хранится на телефоне.
- **Мои предположения, которые стоит проверить**: отбой в четверг 23:30 и в пятницу 23:00,
  подъём в воскресенье 09:00, «иностранный язык = немецкий», начало сессии 11 января (начало января, точной даты нет),
  КР — на практике по предмету в этот день. Всё меняется в «Настройках» или карточке события.

## Банк заданий

- Файл **`data/bank.json`**: задания (`tasks`) и карточки (`cards`). Сейчас там только примеры
  (`"example": true`), чтобы было на чём потренироваться. По истории — задания и карточки
  к темам докладов (`hist-t1` … `hist-t30`; темы 16–22 ждут названий со слайда 33).
- Добавлять свои проще в приложении: «Темы → Добавить задания текстом», формат:

  ```
  Предмет: Физика
  Тема: Кинематика
  Вопрос: Тело прошло 120 м за 20 с. Скорость, м/с?
  Ответ: 6
  Разбор: v = s / t
  ---
  Вопрос: …
  ```

  Несколько верных ответов — через `|`, варианты для выбора — строкой `Варианты: а | б | в`,
  допуск для чисел — `Точность: 0.1`.
- Через чат: присылаешь конспект, фото тетради или список вопросов — получаешь текст в этом
  формате и вставляешь.

## Теория

- Тексты — в **`content/theory/<id-темы>.md`**, у каждого два раздела: `=== brief ===` (кратко,
  шпаргалка) и `=== detailed ===` (подробно, с нуля). Разметка: `## заголовок`, `- список`,
  `1. шаги`, `**жирный**`, `` `код` ``, `{формула}`, `> заметка`, таблицы через `|`, блоки кода.
- После правки: `npm run build:theory` — соберёт **`data/theory.json`** (тесты проверяют,
  что он не устарел). id темы — как в `js/config.js`: `phys-1`, `inf-3`, `hist-t12`…
- Сейчас: кинематика (по уровням игры), 8 практик информатики (из карточек игры «Бит за битом»:
  «кратко» — шпаргалка, «подробно» — теория и какие задачи практики в каком уровне) и 6 практик
  линала (по скриншотам тетради).

## Игры и тренажёры

- Каждая игра — отдельная страница в **`modules/<имя>/index.html`**, запись о ней — в
  `js/modules.js` (предмет, темы, как читать прогресс). Прогресс игра хранит в localStorage
  этого же сайта, поэтому «Рамки» показывают звёзды; `seed.json` — перенесённый прогресс,
  кладётся, если на устройстве игру ещё не открывали.
- Игры из артефактов Claude переносятся как есть: страница целиком плюс ссылка «назад» — в мир
  «Спирали» (`#spiral/<предмет>`).
- Миры «Спирали» — в `js/game.js` (`WORLDS`): предмет, тема, цвет. Игры попадают в мир по
  предмету из `js/modules.js`, звёзды мира = сумма звёзд его игр.

## Разработка

```bash
npm test              # тесты логики: расписание, план, сон, отработка, разбор текста, .ics
npm run serve         # локальный сервер на http://localhost:8080
npm run build:preview # одностраничная сборка для превью (tools/build-preview.mjs)
npm run build:theory  # content/theory/*.md → data/theory.json
```

Структура:

```
index.html, manifest.webmanifest, sw.js   страница, установка на «Домой», офлайн
css/app.css                               стили (светлая и тёмная тема)
js/config.js                              CONFIG и данные из опроса
js/util.js, schedule.js, planner.js       даты, структура дня, планировщик
js/practice.js, parse.js, ics.js          отработка и карточки, разбор текста, календарь .ics
js/store.js, bank.js, nav.js, ui.js       хранение, банк, переходы, элементы интерфейса
js/theory.js, modules.js, portal.js      теория, игры внутри сайта, артефакты по ссылкам
js/views/*.js                             экраны
data/bank.json, data/theory.json          банк заданий, собранная теория
content/theory/                           тексты теории по темам
modules/                                  игры и тренажёры (отдельные страницы)
tools/                                    сборка превью и теории
docs/                                     напоминания и ИИ
tests/                                    тесты (node --test)
```

Шрифт заголовков — Playfair Display (SIL Open Font License, `fonts/OFL.txt`), лежит в папке
приложения и работает без интернета.
