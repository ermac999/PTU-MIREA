=== brief ===
> Практика 5 (5.10) — шпаргалка.

- Со строками можно: переставлять, умножать на число ≠ 0, прибавлять другую строку с множителем. Ранг и решения от этого не меняются.
- Ступенчатый (трапециевидный) вид: под первым ненулевым элементом каждой строки — нули.
- **Ранг** — число **ненулевых** строк в ступенчатом виде.
- Гаусс: расширенная матрица Ā = (A|B) → ступенчатый вид → обратный ход снизу вверх.
- Кронекер–Капелли: {rang A = rang Ā} — система совместна. Если ранг равен n (числу неизвестных) — одно решение, если меньше — бесконечно много, свободных переменных n − r.
- {rang A < rang Ā} — решений нет: в ступенчатом виде строка «0 = число».
- Однородная система (B = 0) всегда совместна. Общее решение — комбинация векторов ФСР, их n − r.
- Проверка: подставь решение в каждое уравнение.

=== detailed ===
> Разбор по твоей практике 5.

## Элементарные преобразования

Со строками матрицы можно:

1. переставлять их местами;
2. умножать строку на число, не равное нулю;
3. прибавлять к строке другую, умноженную на число.

Ранг от этого не меняется, решения системы — тоже.

## Ступенчатый вид и ранг

Цель — ступеньки: в каждой следующей строке первый ненулевой элемент стоит правее, чем в предыдущей, под ним — нули.

**Ранг матрицы** — число **ненулевых** строк после приведения к ступенчатому (трапециевидному) виду.

> Осторожно: в тетради записано «количество нулевых строк». Правильно — ненулевых: нулевые строки как раз отбрасываются.

Пример из практики:

```
[ 1  -2   3 ]
[ 2  -3   4 ]  R₂ − 2R₁
[ 3  -7  11 ]  R₃ − 3R₁
```

Получаем строки (1 −2 3), (0 1 −2), (0 −1 2). Затем R₃ + R₂ = (0 0 0). Ненулевых строк две ⇒ **rang = 2**.

## Метод Гаусса

1. Пишем расширенную матрицу Ā = (A|B): коэффициенты и через черту свободные члены.
2. Прямой ход: приводим к ступенчатому виду.
3. Сравниваем ранги — по теореме ниже.
4. Обратный ход: из последней строки находим последнюю переменную и подставляем вверх.

Пример из практики, система 4×4:

```
 x₁ − 2x₂ +  x₃ −  3x₄ =   6
2x₁ − 5x₂ − 3x₃ +   x₄ = −11
5x₁ − 8x₂ + 6x₃ −  4x₄ =  24
3x₁ −  x₂ +  x₃ + 12x₄ =  −4
```

После прямого хода обратный ход даёт **x₄ = −1, x₃ = 3, x₂ = 1, x₁ = 2**.\
Проверка первого уравнения: 2 − 2 + 3 + 3 = 6 ✓.

## Сколько решений: теорема Кронекера–Капелли

r = rang A, n — число неизвестных, Ā — расширенная матрица.

| Ранги | Что с системой |
|---|---|
| rang A = rang Ā = n | одно решение |
| rang A = rang Ā < n | бесконечно много, свободных переменных n − r |
| rang A < rang Ā | решений нет: появилась строка «0 = число» |

Пример №2 из практики:

```
 x₁ − 2x₂ +  3x₃ =  5
2x₁ − 3x₂ +  4x₃ =  7
3x₁ − 7x₂ + 11x₃ = 21
```

Ступенчатый вид: (1 −2 3 | 5), (0 1 −2 | −3), (0 0 0 | 3). Последняя строка значит 0 = 3 — так не бывает. rang A = 2, rang Ā = 3 ⇒ **решений нет**.

Пример №3:

```
  x₁ −  2x₂ +  2x₃ + 3x₄ =  4
 2x₁ −  6x₂ +  6x₃ + 5x₄ =  3
−3x₁ + 10x₂ − 10x₃ − 7x₄ = −2
```

Ступенчатый вид: (1 −2 2 3 | 4), (0 −2 2 −1 | −5), (0 0 0 0 | 0). rang A = rang Ā = 2 < 4 ⇒ **бесконечно много решений**, свободных переменных 4 − 2 = 2.

Свободными берём x₃ = C₁, x₄ = C₂ и выражаем остальные.\
Из второй строки: x₂ = 5/2 + C₁ − C₂/2.\
Из первой: x₁ = 4 + 2x₂ − 2x₃ − 3x₄ = 9 − 4C₂.

Общее решение: X = (9; 5/2; 0; 0) + C₁·(0; 1; 1; 0) + C₂·(−4; −1/2; 0; 1), C₁, C₂ ∈ ℝ.

Проверка частного решения (9; 5/2; 0; 0): 9 − 5 = 4 ✓, 18 − 15 = 3 ✓, −27 + 25 = −2 ✓.

## Однородная система и ФСР

Если все свободные члены — нули, система **однородная**. Она всегда совместна: подходит x = 0. Если rang < n, ненулевых решений бесконечно много. Их базис — **фундаментальная система решений (ФСР)**, в ней n − r векторов.

Пример №4 из практики. Первые два уравнения: x₁ + x₂ + x₃ + x₄ = 0 и 3x₁ + 2x₂ + x₃ + x₄ = 0, третья строка после прямого хода обнуляется. Ступенчатый вид: (1 1 1 1), (0 −1 −2 −2), (0 0 0 0). Ранг 2, свободные x₃ = C₁, x₄ = C₂.

Из второй строки: x₂ = −2C₁ − 2C₂.\
Из первой: x₁ = −x₂ − x₃ − x₄ = 2C₁ + 2C₂ − C₁ − C₂ = **C₁ + C₂**.

X = C₁·(1; −2; 1; 0) + C₂·(1; −2; 0; 1). ФСР — векторы (1; −2; 1; 0) и (1; −2; 0; 1).

> Осторожно: в тетради x₁ = −C₁ − C₂, и в векторах ФСР сверху −1. Подставь (−1; −2; 1; 0) в первое уравнение: −1 − 2 + 1 + 0 = −2, а должно быть 0. Знак потерян — правильно x₁ = C₁ + C₂.
