## Информация и бит

В теории информации информация — это **уменьшение неопределённости** после получения сообщения.

**1 бит** — информация при выборе одного из двух равновероятных вариантов: орёл или решка.

- 1 байт = 8 бит
- 1 Кбайт = 1024 байта (в информатике степени двойки: 2¹⁰)
- 1 Мбайт = 1024 Кбайт

## Формула Хартли

Если все N сообщений **равновероятны**:

{I = log₂N}

32 сообщения → log₂32 = 5 бит, потому что 2⁵ = 32.

Сообщение из k символов алфавита мощности N:

{I = k · log₂N}

Логарифм нужен, чтобы информация независимых сообщений **складывалась**: варианты перемножаются, а логарифмы складываются.

## Если N — не степень двойки

log₂10 ≈ 3,32 бита. Дробная информация — это нормально.

2³ = 8 < 10 < 16 = 2⁴, значит ответ между 3 и 4.

Но чтобы записать номер одного из 10 сообщений двоичным кодом одинаковой длины, нужно целое число бит: **4** (округляем вверх).

```
import math
print(math.log2(10))  # 3.321928094887362
print(math.log2(32))  # 5.0 — всегда float
```

## Энтропия Шеннона

Если вероятности сообщений **разные**:

{H = −Σ pᵢ · log₂pᵢ}

H — среднее количество информации на одно сообщение. Минус нужен, потому что log₂p < 0 при p < 1.

Пример: p = {0.5, 0.25, 0.125, 0.125}

log₂0.5 = −1, log₂0.25 = −2, log₂0.125 = −3

H = 0.5·1 + 0.25·2 + 0.125·3 + 0.125·3 = **1,75 бита**

## Когда энтропия максимальна

- Все n сообщений равновероятны → энтропия максимальна: **Hₘₐₓ = log₂n**. Это совпадает с Хартли.
- Чем предсказуемее источник, тем меньше H: {0.7, 0.1, 0.1, 0.1} → ≈1,357 < 2.
- Одно сообщение с p = 1 → H = 0: неопределённости нет.
- Сумма вероятностей всегда равна 1 — это **нормировка**.

## Энтропия на Python

```
import math
p = [0.5, 0.25, 0.125, 0.125]
H = -sum(pi * math.log2(pi) for pi in p)
print(H)  # 1.75
```

Из частот в вероятности: делим каждую частоту на сумму всех частот.

```
f = [8, 4, 2, 2]
p = [x / sum(f) for x in f]
# [0.5, 0.25, 0.125, 0.125]
```
