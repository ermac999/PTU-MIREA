## Формы представления

- **Текстовая** — символы, кодируются байтами по кодировке.
- **Числовая** — двоичные слова фиксированной или переменной длины.
- **Графическая** — числа: цвет и яркость каждой точки.
- **Логическая** — истина/ложь, кодируется битами.

Кодирование меняет **форму** записи, но не смысл.

## Алфавит, код, кодовое слово

**Алфавит** — конечное множество символов исходных сообщений.

**Код** — соответствие «символ → кодовое слово», например A → 00.

**Кодовое слово** — последовательность символов кодового алфавита (у нас 0 и 1) для одного символа.

Главное требование — сообщение можно **однозначно** восстановить.

## Код фиксированной длины

Все слова одинаковой длины k. Минимальное k — наименьшее, при котором

{2ᵏ ≥ N}

{A, B, C}: N = 3 → k = 2. A = 00, B = 01, C = 10.

ABACAB ⇒ 00 01 00 10 00 01 → **V = 6·2 = 12 бит**.

+ Простое декодирование: режем по k бит.\
− Не учитывает частоты; комбинация 11 пропадает зря.

## Код переменной длины

Частым символам — короткие слова: A = 0, B = 10, C = 11.

ABACAB ⇒ 0 10 0 11 0 10 = 010011010 → **9 бит**.

Средняя длина: 9 / 6 = **1,5 бита**.

Важно **условие Фано**: ни одно кодовое слово не является началом другого. Тогда декодирование однозначно.

## Байтовое кодирование UTF-8

- Латиница, цифры, пробел — **1 байт** на символ.
- Кириллица — **2 байта** на букву.

A = 41₁₆ = 01000001, B = 42₁₆, C = 43₁₆, буквы идут подряд.

ABACAB → 41 42 41 43 41 42 → **6 байт = 48 бит**.

```
text = "ABACAB"
encoded = text.encode("utf-8")
print(len(encoded))  # 6
```

## Как сравнивать способы

Критерии: объём, средняя длина слова, избыточность, однозначность декодирования, удобство хранения и передачи.

ABACAB: **переменный 9 < фиксированный 12 < UTF-8 48**.

- Переменный — экономия памяти при ограниченном алфавите.
- Фиксированный — когда нужно простое и надёжное декодирование.
- UTF-8 — для обмена между разными системами, хоть и больше по объёму.
