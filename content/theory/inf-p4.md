## Позиционная система

Значение цифры зависит от её **позиции**. Вес позиции i — это qⁱ (q — основание).

{(aₙ…a₁a₀)_q = Σ aᵢ·qⁱ}

Цифры: от 0 до q − 1. В 16-й системе после 9 идут A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

Позиции считаются **справа, с нуля**.

## В десятичную: развёртка

Умножаем каждую цифру на вес позиции и складываем.

(312)₄ = 3·4² + 1·4¹ + 2·4⁰ = 48 + 4 + 2 = **54**

(2A)₁₆ = 2·16 + 10·1 = **42**

Метод универсальный: работает для любого основания.

## Из десятичной: деление

Делим на q, записываем остатки, остатки читаем **снизу вверх**.

```
45 ÷ 3 = 15, остаток 0
15 ÷ 3 = 5,  остаток 0
 5 ÷ 3 = 1,  остаток 2
 1 ÷ 3 = 0,  остаток 1
```

Снизу вверх: 1 2 0 0 → **(1200)₃**

## Из десятичной: по степеням

Находим наибольшую степень q, которая не превышает число. Сколько раз она помещается — это старшая цифра. Остаток раскладываем дальше.

45 в троичную: 27 ≤ 45 < 81.\
45 = **1**·27 + 18; 18 = **2**·9 + 0; 0 = **0**·3; 0 = **0**·1 → (1200)₃

Оба метода дают одинаковый ответ.

## Проверки и длина записи

- Цифра ≥ основания — запись некорректна: «19» не бывает в 8-й системе.
- Двойное преобразование: перевели туда и обратно — число должно совпасть.
- Длина записи: **L = ⌊log_q N⌋ + 1**. Чем больше основание, тем короче: 255 = 11111111₂ = 377₈ = FF₁₆.
