=== brief ===
> Практика 3 (21.09) — шпаргалка.

- Крамер для системы n×n: {xᵢ = Δᵢ / Δ}. Δᵢ — определитель, в котором i-й столбец заменён столбцом свободных членов b.
- {Δ ≠ 0} ⇒ решение единственное.
- Большой определитель — приведи к треугольному виду (Rᵢ − k·Rⱼ его не меняет) и перемножь диагональ.
- Обратная матрица: {A⁻¹ = (1/det A)·Ãᵀ}, где Ã — матрица алгебраических дополнений {Aᵢⱼ = (−1)ⁱ⁺ʲ·Mᵢⱼ}.
- Существует только при {det A ≠ 0}. Проверка: {A·A⁻¹ = E}.
- 2×2: {(a b; c d)⁻¹ = 1/(ad − bc)·(d −b; −c a)}.
- В Aᵢⱼ элемент aᵢⱼ **не умножается** — на него умножают только при разложении определителя.
- Ответ всегда проверяй подстановкой в уравнения.

=== detailed ===
> Разбор по твоей практике 3 и черновику к ней.

## Метод Крамера

Система из n уравнений с n неизвестными:

```
a₁₁x₁ + … + a₁ₙxₙ = b₁
  …
aₙ₁x₁ + … + aₙₙxₙ = bₙ
```

1. Считаем главный определитель Δ из коэффициентов. Если {Δ ≠ 0}, решение есть и оно единственное.
2. Для каждого xᵢ заменяем **i-й столбец** столбцом свободных членов b и считаем Δᵢ.
3. {xᵢ = Δᵢ / Δ}.

Пример из практики:

```
2x₁ −  x₂ =  7
4x₁ + 5x₂ = −7
```

Δ = |2 −1; 4 5| = 10 + 4 = 14\
Δ₁ = |7 −1; −7 5| = 35 − 7 = 28 ⇒ x₁ = 28/14 = **2**\
Δ₂ = |2 7; 4 −7| = −14 − 28 = −42 ⇒ x₂ = −42/14 = **−3**

Проверка: 2·2 − (−3) = 7 ✓, 4·2 + 5·(−3) = −7 ✓. **Всегда подставляй ответ** — так ловятся ошибки в знаках.

## Крамер для 3×3

```
 x₁ + 2x₂ + 3x₃ = 5
4x₁ + 5x₂ + 6x₃ = 8
7x₁ + 8x₂       = 2
```

Δ = 27 ≠ 0, Δ₂ = 54, Δ₃ = 27. Δ₁ = |5 2 3; 8 5 6; 2 8 0|.

> Проверь Δ₁ у себя. Вынеси 2 из третьей строки, сделай R₁ − 5R₃ и R₂ − 8R₃, вынеси ещё 3 и 3. Получится 18·|−6 1; −9 2| = 18·(−12 + 9) = 18·(−3) = **−54** — здесь легко потерять минус.

x₁ = −54/27 = **−2**, x₂ = 54/27 = **2**, x₃ = 27/27 = **1**.\
Проверка: −2 + 4 + 3 = 5 ✓, −8 + 10 + 6 = 8 ✓, −14 + 16 = 2 ✓.

## Определитель через треугольный вид

Свойство: если прибавить к строке другую, умноженную на число, определитель не меняется. Делаем нули под диагональю и перемножаем диагональ.

Практика, №1:

```
| 1   2   7 |
| 2   1   3 |  R₂ − 2R₁
| 5  -2   1 |  R₃ − 5R₁
```

Получаем |1 2 7; 0 −3 −11; 0 −12 −34|, затем R₃ − 4R₂ → |1 2 7; 0 −3 −11; 0 0 10|.\
Δ = 1·(−3)·10 = **−30**.

Поменял строки местами — поменяй знак. Вынес множитель из строки — не забудь умножить на него в конце.

## Обратная матрица

{A·A⁻¹ = A⁻¹·A = E}. Существует, только если **{det A ≠ 0}**.

1. Считаем |A|. Если 0, обратной нет.
2. Для **каждого** элемента считаем алгебраическое дополнение {Aᵢⱼ = (−1)ⁱ⁺ʲ·Mᵢⱼ}.
3. Ставим их в матрицу Ã на те же места и транспонируем.
4. {A⁻¹ = (1/|A|)·Ãᵀ}.
5. Проверка: A·A⁻¹ = E.

Для 2×2 короче: {(a b; c d)⁻¹ = 1/(ad − bc)·(d −b; −c a)} — диагональ меняем местами, у побочной меняем знак.

Пример из практики: A = (4 5; 2 3), |A| = 12 − 10 = 2.\
A⁻¹ = ½·(3 −5; −2 4) = **(3/2 −5/2; −1 2)**.\
Проверка: (4 5; 2 3)·(3/2 −5/2; −1 2) = (6 − 5, −10 + 10; 3 − 3, −5 + 6) = (1 0; 0 1) ✓.

## Пример 3×3 — и частая ошибка

A = (1 2 3; 0 1 4; 5 6 0). Разложение по первому столбцу: |A| = 1·(−24) + 0 + 5·5 = **1**.

> Осторожно, в черновике к П3 миноры умножены на элементы: A₁₂ = 2·|0 4; 5 0|, A₁₃ = 3·|0 1; 5 6| и так далее. Для обратной матрицы так нельзя. Алгебраическое дополнение — только знак и минор: {Aᵢⱼ = (−1)ⁱ⁺ʲ·Mᵢⱼ}. На элемент aᵢⱼ умножают только при разложении определителя.

Правильные дополнения:

| | столбец 1 | столбец 2 | столбец 3 |
|---|---|---|---|
| строка 1 | A₁₁ = −24 | A₁₂ = 20 | A₁₃ = −5 |
| строка 2 | A₂₁ = 18 | A₂₂ = −15 | A₂₃ = 4 |
| строка 3 | A₃₁ = 5 | A₃₂ = −4 | A₃₃ = 1 |

Транспонируем и делим на |A| = 1:

```
      [ -24   18    5 ]
A⁻¹ = [  20  -15   -4 ]
      [  -5    4    1 ]
```

Проверка первой строкой A: 1·(−24) + 2·20 + 3·(−5) = 1 ✓, 1·18 + 2·(−15) + 3·4 = 0 ✓.
