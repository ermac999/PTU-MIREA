=== brief ===
> Практика 6 (12.10, анал. геом) — шпаргалка.

- {a·b = |a|·|b|·cos φ}; в координатах {a·b = x₁x₂ + y₁y₂ + z₁z₂}.
- Свойства: {a·b = b·a}, {(λa)·b = λ(a·b)}, {a·(b + c) = a·b + a·c}.
- {a·b = 0} ⇔ a ⊥ b или один из векторов нулевой.
- Скалярный квадрат {a·a = |a|²}, отсюда {|a| = √(a·a)}; в координатах {|a| = √(x² + y² + z²)}.
- Угол: {cos φ = a·b / (|a|·|b|)}; cos < 0 — угол тупой.
- Вектор по двум точкам: из координат конца вычесть координаты начала, {AB = B − A}.
- a, b, c — базис в ℝ³ ⇔ определитель из их координат ≠ 0.
- Разложить d по базису: {d = x·a + y·b + z·c} — система из трёх уравнений.

=== detailed ===
> Разбор по анал. геому 12.10. В тетради «Опр.» осталось пустым — вот определение.

## Определение

Скалярное произведение двух векторов — **число**:

{a·b = |a|·|b|·cos φ}, где φ — угол между векторами.

В координатах (в прямоугольной системе): если a = (x₁; y₁; z₁), b = (x₂; y₂; z₂), то

{a·b = x₁x₂ + y₁y₂ + z₁z₂}

## Свойства

- {a·b = b·a}
- {(λa)·b = a·(λb) = λ(a·b)}
- {a·(b + c) = a·b + a·c} и {(a + b)·c = a·c + b·c} — скобки раскрываются как с числами
- {a·a = |a|²} — скалярный квадрат, потому что cos 0 = 1. Отсюда {|a| = √(a·a)}
- {a·b = 0} ⇔ a ⊥ b или один из векторов нулевой
- Угол между векторами: {cos φ = a·b / (|a|·|b|)}

## №1: при каком λ векторы перпендикулярны

Дано: |a| = 3, |b| = 5, c = a + λb, d = a − λb. Найти λ, при котором c ⊥ d.

c ⊥ d ⇔ c·d = 0. Раскрываем скобки:\
(a + λb)·(a − λb) = a·a − λa·b + λb·a − λ²b·b = |a|² − λ²|b|²\
9 − 25λ² = 0 ⇒ λ² = 9/25 ⇒ **λ = ±3/5**.

Средние слагаемые сократились, потому что a·b = b·a.

## №2: угол треугольника по координатам

A(2; 3; 1), B(4; 1; −2), C(6; 3; 7). Найти ∠A.

Угол A — между векторами AB и AC, оба выходят из A.\
AB = B − A = (2; −2; −3), |AB| = √(4 + 4 + 9) = √17\
AC = C − A = (4; 0; 6), |AC| = √(16 + 36) = √52 = 2√13\
AB·AC = 2·4 + (−2)·0 + (−3)·6 = −10

cos A = −10 / (√17·2√13) = −5/√221 < 0, угол **тупой**:\
∠A = arccos(−5/√221) = π − arccos(5/√221) ≈ 109,7°.

## №3: угол между a = p − 2q и b = p + q

Дано: |p| = 3, |q| = 2, угол (p, q) = 2π/3. Найти угол (a, b).

1. p·q = 3·2·cos(2π/3) = 6·(−1/2) = −3.
2. a·b = (p − 2q)·(p + q) = |p|² − p·q − 2|q|² = 9 + 3 − 8 = 4.
3. |a|² = (p − 2q)·(p − 2q) = |p|² − 4p·q + 4|q|² = 9 + 12 + 16 = 37 ⇒ |a| = √37.
4. |b|² = (p + q)·(p + q) = |p|² + 2p·q + |q|² = 9 − 6 + 4 = 7 ⇒ |b| = √7.
5. cos(a, b) = 4 / (√37·√7) = **4/√259** ≈ 0,249.

## №4: базис и разложение по нему

a = (1; 2; 1), b = (0; −1; 1), c = (2; 0; 1), d = (5; 8; 2). Доказать, что a, b, c — базис в ℝ³, и разложить d по нему.

Базис ⇔ векторы линейно независимы ⇔ определитель из их координат не равен нулю:\
det (1 2 1; 0 −1 1; 2 0 1) = 1·(−1 − 0) − 2·(0 − 2) + 1·(0 + 2) = −1 + 4 + 2 = 5 ≠ 0 ✓.

Ищем d = x·a + y·b + z·c. По координатам получается система:

```
 x      + 2z = 5
2x −  y      = 8
 x +  y +  z = 2
```

Решение Крамером или Гауссом: **x = 3, y = −2, z = 1**, то есть d = 3a − 2b + c.\
Проверка: 3·(1; 2; 1) − 2·(0; −1; 1) + (2; 0; 1) = (5; 8; 2) ✓.
