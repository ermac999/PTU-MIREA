=== detailed ===
> Разбор с нуля по твоей практике 1 и лекции 1. Матрицы пишу строками через «;»: (1 2; 3 4) — первая строка 1 2, вторая 3 4.

## Что такое матрица

Матрица — прямоугольная таблица чисел. Размер **m×n**: m строк и n столбцов. Элемент {aᵢⱼ} стоит в строке i и столбце j — сначала строка, потом столбец.

```
A = [ 1  2 ]     a₁₂ = 2
    [ 3  4 ]     a₂₁ = 3
```

## Виды матриц

- **Прямоугольная** — строк не столько же, сколько столбцов (m ≠ n).
- **Квадратная** — m = n. У неё есть **главная диагональ**: линия от левого верхнего угла к правому нижнему (a₁₁, a₂₂, …).
- **Матрица-строка** — одна строка (1×n). **Матрица-столбец** — один столбец (m×1).
- **Диагональная** — квадратная, всё вне главной диагонали равно нулю, на диагонали — любые числа.
- **Единичная E** — диагональная с единицами: (1 0; 0 1). Работает как единица: {A·E = E·A = A}.
- **Треугольная** — нули строго ниже главной диагонали (верхнетреугольная) или строго выше (нижнетреугольная).
- **Симметричная** — элементы отражаются относительно главной диагонали: {aᵢⱼ = aⱼᵢ}.

```
верхнетреугольная  нижнетреугольная
[ 1  5  7 ]        [ 6  0  0 ]
[ 0  2  4 ]        [ 9  7  0 ]
[ 0  0  3 ]        [ 1  5  2 ]

симметричная
[ 1  4  5 ]
[ 4  2  6 ]
[ 5  6  3 ]
```

## Сложение и умножение на число

Складывать можно только матрицы **одного размера** — поэлементно:

(1 2; 3 4) + (5 6; 7 8) = (1+5 2+6; 3+7 4+8) = **(6 8; 10 12)**.

Свойства: {A + B = B + A}, {(A + B) + C = A + (B + C)}.

На число умножается **каждый** элемент: 2·(1 2; 0 3) = (2 4; 0 6).

Свойства: {λ(A + B) = λA + λB}, {(λ + μ)A = λA + μA}, {λ(μA) = (λμ)A}.

## Умножение матриц

Умножать можно, только если **столбцов у первой столько же, сколько строк у второй**:

{(m×n) · (n×k) = (m×k)}

Элемент результата — **строка i первой матрицы на столбец j второй**: попарно умножаем и складываем.

{cᵢⱼ = aᵢ₁·b₁ⱼ + aᵢ₂·b₂ⱼ + … + aᵢₙ·bₙⱼ}

Пример из практики:

```
[ 1  2 ]   [ 5  0 ]   [  5  0 ]
[ 3  4 ] · [ 0  0 ] = [ 15  0 ]
```

c₂₁ = 3·5 + 4·0 = 15. А в обратном порядке B·A = (5 10; 0 0) — другой ответ. **Порядок множителей важен: {A·B ≠ B·A}.**

Ещё пример из тетради: (1 2; 3 6)·(2 6; −1 −3) = (0 0; 0 0). Обе матрицы ненулевые, а произведение нулевое. С числами так не бывает, с матрицами — бывает.

## Почему A² − B² ≠ (A − B)(A + B)

Раскроем скобки, не переставляя множители:

{(A − B)(A + B) = A² + AB − BA − B²}

У чисел AB − BA = 0, у матриц — нет. Пример из практики: A = (1 −2; 3 −4), B = (5 0; 1 2).

- {A² − B² = (−5 6; −9 10) − (25 0; 7 4) = (−30 6; −16 6)}
- {(A − B)(A + B) = (−4 −2; 2 −6)·(6 −2; 4 −2) = (−32 12; −12 8)}

Ответы разные: формулы сокращённого умножения для матриц не работают.

## Транспонирование

Строки становятся столбцами: (1 2 3; 4 5 6)ᵀ = (1 4; 2 5; 3 6).

- {(A + B)ᵀ = Aᵀ + Bᵀ}
- {(A·B)ᵀ = Bᵀ·Aᵀ} — порядок меняется!
- {(Aᵀ)ᵀ = A}

## Линейная комбинация

Берём объекты (строки, столбцы, векторы, матрицы), умножаем на числа и складываем:

{c₁v₁ + c₂v₂ + … + cₙvₙ}

Пример: v₁ = (1; 2), v₂ = (3; 4), коэффициенты 2 и −1:\
2·(1; 2) − 1·(3; 4) = (2; 4) − (3; 4) = **(−1; 0)**.
