## Зачем избыточность

При передаче бит может перевернуться: 0 → 1 или 1 → 0.

Добавляя **лишние (контрольные) биты**, можно:

- обнаружить, что ошибка есть;
- иногда найти её позицию;
- исправить без повторной передачи.

## Расстояние Хэмминга

Число позиций, где два слова различаются.

```
1010110
1000011
  ^ ^ ^   → d = 3
```

Минимальное расстояние кода dₘᵢₙ:

- обнаруживает до **dₘᵢₙ − 1** ошибок;
- исправляет до **⌊(dₘᵢₙ − 1)/2⌋**.

```
d = sum(x != y for x, y in zip(a, b))
```

## Бит чётности

Дописываем бит p так, чтобы единиц стало **чётное** число: p = (число единиц) mod 2.

110101: единиц 4 → p = 0 → **1101010**.

- Ловит нечётное число ошибок (1, 3…).
- Пропускает чётное (2, 4…).
- Не знает, где ошибка, — исправить не может.

## Троирование

Каждый бит повторяем трижды: 0 → 000, 1 → 111.

Декодируем **по большинству**: 101 → 1, 001 → 0.

1010 → 111 000 111 000. Ошибка в первой тройке: 101 → всё равно 1.

Исправляет 1 ошибку в каждой тройке, но объём **в 3 раза** больше.

## Код Хэмминга (7,4)

4 бита данных + 3 контрольных = 7 бит.

| 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|
| p1 | p2 | d1 | p4 | d2 | d3 | d4 |

p1 = d1⊕d2⊕d4 (позиции 1, 3, 5, 7)\
p2 = d1⊕d3⊕d4 (позиции 2, 3, 6, 7)\
p4 = d2⊕d3⊕d4 (позиции 4, 5, 6, 7)

1011 → p1 = 0, p2 = 1, p4 = 0 → **0110011**.

⊕ — XOR: 1, если единиц нечётное число.

## Синдром: где ошибка

s1 = b1⊕b3⊕b5⊕b7\
s2 = b2⊕b3⊕b6⊕b7\
s4 = b4⊕b5⊕b6⊕b7

{позиция = s1 + 2·s2 + 4·s4}

0 — ошибок нет. Иначе инвертируем бит с этим номером.

0110111: s1 = 1, s2 = 0, s4 = 1 → синдром **5** → исправляем: 0110011.
