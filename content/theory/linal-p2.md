=== brief ===
> Практика 2 — шпаргалка. Определитель пишут как det A, |A| или Δ.

- Определитель — число, есть только у квадратной матрицы.
- 2×2: {|a b; c d| = ad − bc}.
- 3×3, правило треугольников: {a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂ − a₁₃a₂₂a₃₁ − a₁₁a₂₃a₃₂ − a₁₂a₂₁a₃₃}.
- Минор {Mᵢⱼ} — определитель без строки i и столбца j. Алгебраическое дополнение {Aᵢⱼ = (−1)ⁱ⁺ʲ·Mᵢⱼ}, знаки шахматкой: (+ − +; − + −; + − +).
- Разложение по строке i: {det A = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + … + aᵢₙAᵢₙ}, так же по столбцу. Бери строку с нулями.
- Общий множитель строки выносится за знак определителя.
- Переставили две строки — знак меняется.
- Две одинаковые или пропорциональные строки, или нулевая строка — det = 0.
- Прибавить к строке другую, умноженную на число, — det не меняется.
- {det Aᵀ = det A}, {det(AB) = det A·det B}; у треугольной det — произведение диагонали.

=== detailed ===
> Разбор по твоей практике 2. Определитель пишут как det A, |A| или Δ.

## Что это

Определитель — **число**, которое считают по квадратной матрице. Если det A = 0, матрица вырожденная: у неё нет обратной, и систему с ней по Крамеру не решить.

## 2×2

{|a b; c d| = a·d − b·c} — главная диагональ минус побочная.

Пример: |1 2; 3 4| = 4 − 6 = −2.

## 3×3: правило треугольников

Три произведения со знаком «+»: главная диагональ и два треугольника вдоль неё. Три со знаком «−»: побочная диагональ и два треугольника вдоль неё.

{Δ = a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂ − a₁₃a₂₂a₃₁ − a₁₁a₂₃a₃₂ − a₁₂a₂₁a₃₃}

Пример из практики: det (1 2 1; 0 1 3; 1 −2 4):\
4 + 6 + 0 − 1 − (−6) − 0 = **15**.

> Осторожно, в черновике к П3: det (1 2 3; 4 5 6; 7 8 1) = (5 + 96 + 84) − 48 − 8 − 105 = 185 − 161 = **24**. В тетради записано 76 — ошибка в последнем действии, сами произведения верные.

## Минор и алгебраическое дополнение

- **Минор** {Mᵢⱼ} — определитель, который остаётся, если вычеркнуть строку i и столбец j.
- **Алгебраическое дополнение** {Aᵢⱼ = (−1)ⁱ⁺ʲ·Mᵢⱼ} — тот же минор со знаком. Знаки идут шахматкой:

```
[ +  −  + ]
[ −  +  − ]
[ +  −  + ]
```

Пример: в матрице (1 2 3; 0 1 4; 5 6 0) вычеркнем строку 1 и столбец 2, останется |0 4; 5 0| = −20. Это M₁₂ = −20, а A₁₂ = (−1)¹⁺²·(−20) = **20**.

## Разложение по строке или столбцу

{det A = aᵢ₁·Aᵢ₁ + aᵢ₂·Aᵢ₂ + … + aᵢₙ·Aᵢₙ}

Каждый элемент строки умножаем на **его** алгебраическое дополнение и складываем. Подходит любая строка или столбец — выбирай ту, где больше нулей.

Для 3×3 по первой строке:

{Δ = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁)}

Пример из практики, по первому столбцу:

```
| 5  -2  -3 |
| 1   0   4 |
| 7   2  -1 |
```

5·|0 4; 2 −1| − 1·|−2 −3; 2 −1| + 7·|−2 −3; 0 4|\
= 5·(0 − 8) − 1·(2 + 6) + 7·(−8 − 0)\
= −40 − 8 − 56 = **−104**.

По второй строке, где есть ноль, — тот же ответ: 1·(−8) + 0 + 4·(−24) = −104.

## Уравнения с определителем

Раскрой определитель — получится обычное уравнение.

Пример: |x + 1 x − 1; x x + 1| = 0\
(x + 1)² − x(x − 1) = x² + 2x + 1 − x² + x = 3x + 1 = 0 ⇒ **x = −1/3**.

## Свойства — ими упрощают счёт

1. Общий множитель строки или столбца выносится за знак определителя.
2. Если строка — сумма двух строк, определитель распадается на сумму двух определителей.
3. Переставили две строки — знак меняется.
4. Две одинаковые или пропорциональные строки, или строка из нулей — определитель равен 0.
5. К строке можно прибавить другую строку, умноженную на число, — определитель **не меняется**. На этом стоит приведение к треугольному виду.
6. {det Aᵀ = det A}: всё, что верно для строк, верно и для столбцов.
7. У треугольной матрицы определитель — произведение элементов главной диагонали.
8. {det(A·B) = det A · det B}.
