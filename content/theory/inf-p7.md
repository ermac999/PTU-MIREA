> Практика 7: Представление положительных целых чисел. Прямой, обратный и дополнительный код для отрицательных чисел. Шпаргалка — из игры «Бит за битом» (модуль 7).

- Без знака, n бит: 0 … 2ⁿ − 1
- Положительные во всех кодах одинаковы
- Прямой: знак 1 + модуль в n − 1 битах
- Обратный: инвертировать все биты +x
- Дополнительный: инвертировать и +1 (= 2ⁿ − |x|)
- Доп. код: −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1 (8 бит: −128 … 127)
- Прямой и обратный: −(2ⁿ⁻¹ − 1) … 2ⁿ⁻¹ − 1, два нуля
- Из доп. кода: старший бит 1 → значение = число − 2ⁿ
- 11111111: доп. = −1, обратный = −0, прямой = −127

## Беззнаковые числа

Положительное целое — обычная двоичная запись, дополненная нулями до n бит.

25 → 11001 → в 8 битах **00011001**.

{0 ≤ X ≤ 2ⁿ − 1}

8 бит: 0 … 255.

## Знаковый разряд

Для отрицательных чисел старший бит отдают под **знак**: 0 — плюс, 1 — минус.

Есть три способа записи: **прямой, обратный и дополнительный** код.

Положительные числа во всех трёх записываются **одинаково**. Различаются только отрицательные.

## Прямой код

Знак + модуль в оставшихся n − 1 битах.

−13 (8 бит): модуль 13 = 0001101 → **1**0001101

- Два нуля: 00000000 и 10000000.
- Сложно складывать числа разных знаков.

## Обратный код

Пишем +x в n битах и **инвертируем все биты**: 0 ↔ 1.

13 = 00001101 → −13 = **11110010**

Тоже два нуля: 00000000 и 11111111. Арифметика требует особых правил.

## Дополнительный код

Инвертируем и **прибавляем 1**.

−13: 00001101 → 11110010 → +1 → **11110011**

Быстрая проверка: 2ⁿ − |x| = 256 − 13 = 243 = 11110011₂.

- Один ноль.
- Один алгоритм сложения для любых знаков.
- Простая аппаратная реализация — поэтому его и используют.

```
format((1 << 8) + (-13), '08b')  # '11110011'
```

## Диапазоны и обратный перевод

Дополнительный код, n бит:

{−2ⁿ⁻¹ ≤ X ≤ 2ⁿ⁻¹ − 1}

8 бит: **−128 … 127**. Прямой и обратный: −127 … 127 (из-за двух нулей).

Из доп. кода в число: если старший бит 1, значение = (число без знака) − 2ⁿ. 11110011 = 243 − 256 = −13.
