# ИИ-подсказки: честно, что есть сейчас и как добавить позже

## Что есть сейчас

Внутри «Рамок» **нет искусственного интеллекта**. Это статический сайт на GitHub Pages: у него нет
сервера, а чтобы обратиться к модели, нужен секретный API-ключ. Ключ нельзя положить в сайт —
его увидит любой, кто откроет код страницы. Поэтому приложение ничего не «понимает» и не делает вид:

- **план** собирается по правилам: дедлайны, часы подготовки по типу события, уровень предмета,
  свободные окна, минимум сна (`js/planner.js`);
- **отработка** сравнивает ответ с эталоном из банка заданий (`js/practice.js`);
- **разбор вставленного текста** — правила и ключевые слова (`js/parse.js`).

**Как пополнять банк без ИИ в приложении — через чат.** Присылаешь в чат конспект, фото тетради,
список вопросов к зачёту или задачи с практики → получаешь текст в формате шаблона
(«Предмет / Тема / Вопрос / Ответ / Разбор») → вставляешь в «Темы → Добавить задания текстом».
Это бесплатно сверх подписки на чат и не требует серверов.

## Что можно добавить позже

1. **Подсказка к задаче.** Кнопка «Подсказка» на экране отработки: модель видит задачу, твой ответ
   и кусок конспекта и даёт наводящий вопрос, а не готовое решение.
2. **Разбор ошибки.** После неверного ответа — объяснение, где именно ошибка.
3. **Задания из конспекта.** Вставил конспект — получил 10 задач с ответами и разборами прямо
   в приложении, без чата.
4. **Карточки из лекции.** Вопросы для самопроверки из текста или списка билетов.

## Что для этого нужно

```
iPhone (сайт «Рамки»)  ──►  маленький сервер-прокси  ──►  API Anthropic (Claude)
                            хранит ключ, считает лимиты
```

- **Аккаунт и ключ API** в консоли Anthropic (platform.claude.com) и способ оплаты.
  Важно: API доступен не во всех странах — сначала проверь список поддерживаемых регионов
  и способы оплаты, потом что-то строй.
- **Прокси**, например Cloudflare Worker (бесплатного тарифа для одного человека хватает
  с запасом; актуальные лимиты — на сайте Cloudflare). Ключ хранится как секрет Worker'а,
  сайт его никогда не видит.
- **Защита от чужих запросов**: разрешить запросы только с адреса твоего сайта (CORS),
  простой пароль приложения в заголовке, суточный лимит запросов, и лимит расходов
  в консоли Anthropic — чтобы сумма не могла вырасти неожиданно.
- **Изменения в приложении**: кнопка «Подсказка», поле для адреса прокси и пароля в настройках,
  обработка ошибок («нет сети» — подсказка недоступна, всё остальное работает как раньше).

## Сколько это может стоить

Цены Anthropic на октябрь 2026 (за 1 млн токенов; 1 000 токенов — это примерно
600–700 слов русского текста). Проверяй актуальные цены на странице тарифов перед стартом.

| Модель | Вход | Выход | Комментарий |
|---|---|---|---|
| Claude Opus 5.5 | $4 | $20 | самая сильная из обычных; по умолчанию в примере ниже |
| Claude Sonnet 5.5 | $2 | $10 | быстрее и вдвое дешевле |
| Claude Haiku 5.5 | $0,10 | $0,50 | самая дешёвая (до 100 тыс. токенов в запросе) |

Ещё два способа сэкономить:
- **Batch API** — запросы, которые можно подождать (например, «сделай задания из 10 конспектов
  за ночь»), стоят **на 50% дешевле**.
- **Кэширование промпта** — повторяющееся начало запроса (инструкция, конспект) при повторном
  использовании читается из кэша примерно в 10 раз дешевле обычного входа. Работает, только если
  повторяющаяся часть достаточно длинная (от 512 до 4096 токенов в зависимости от модели) — для
  коротких подсказок может не сработать.

**Примерный расчёт.** Подсказка: ~1 500 токенов на входе (инструкция + задача + ответ + кусок
конспекта) и ~700 на выходе (модель думает перед ответом — эти токены тоже оплачиваются как выход).

| | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|
| Одна подсказка | ≈ $0,02 | ≈ $0,01 | ≈ $0,0005 |
| 15 подсказок в день, месяц (≈450) | ≈ $9 | ≈ $4,5 | ≈ $0,25 |
| Задания из страницы конспекта (3 000 вход / 2 500 выход), через Batch API | ≈ $0,03 | ≈ $0,016 | ≈ $0,001 |
| 40 страниц конспектов за семестр | ≈ $1,2 | ≈ $0,6 | ≈ $0,03 |

Какую модель брать — решать тебе: в коде это одна строка. Для первокурсной математики
и физики разница в качестве подсказок между моделями меньше, чем разница в цене, — имеет
смысл попробовать одну и ту же задачу на двух моделях и сравнить.

## Набросок прокси (Cloudflare Worker, TypeScript)

Создать проект: `npm create cloudflare@latest ramki-ai`, затем `npm install @anthropic-ai/sdk`,
положить ключ: `npx wrangler secret put ANTHROPIC_API_KEY` и пароль приложения:
`npx wrangler secret put APP_TOKEN`, опубликовать: `npx wrangler deploy`.

```ts
import Anthropic from "@anthropic-ai/sdk";

export interface Env {
  ANTHROPIC_API_KEY: string;
  APP_TOKEN: string;
}

const CORS = {
  "Access-Control-Allow-Origin": "https://ermac999.github.io", // адрес сайта на GitHub Pages
  "Access-Control-Allow-Headers": "content-type, x-app-token",
  "Access-Control-Allow-Methods": "POST, OPTIONS",
};

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    if (request.method === "OPTIONS") return new Response(null, { headers: CORS });
    if (request.method !== "POST" || request.headers.get("x-app-token") !== env.APP_TOKEN) {
      return new Response("forbidden", { status: 403, headers: CORS });
    }
    const body = (await request.json()) as { task: string; answer: string; notes?: string };
    const client = new Anthropic({ apiKey: env.ANTHROPIC_API_KEY });

    try {
      const response = await client.beta.messages.create({
        model: "claude-opus-5-5",
        max_tokens: 4000, // подсказка короткая; запас — на размышления модели
        output_config: { effort: "low" }, // короткие подсказки не требуют долгих размышлений
        // Если модель откажется отвечать, запрос сам повторится на подходящей запасной модели
        betas: ["server-side-fallback-2026-07-01"],
        fallbacks: "default",
        system:
          "Ты спокойный репетитор студента-первокурсника. Дай подсказку к задаче: " +
          "наводящий вопрос или следующий шаг, не полное решение. 3–5 предложений, без упрёков.",
        messages: [
          {
            role: "user",
            content: `Задача: ${body.task}\nМой ответ: ${body.answer}\n${body.notes ? `Конспект: ${body.notes}` : ""}`,
          },
        ],
      });
      if (response.stop_reason === "refusal") return Response.json({ hint: null }, { headers: CORS });
      const hint = response.content
        .filter((b): b is Anthropic.Beta.BetaTextBlock => b.type === "text")
        .map((b) => b.text)
        .join("\n");
      return Response.json({ hint }, { headers: CORS });
    } catch (error) {
      if (error instanceof Anthropic.RateLimitError) {
        return Response.json({ error: "Слишком много запросов, попробуй через минуту." }, { status: 429, headers: CORS });
      }
      if (error instanceof Anthropic.APIError) {
        return Response.json({ error: `Сервис подсказок недоступен (${error.status}).` }, { status: 502, headers: CORS });
      }
      throw error;
    }
  },
};
```

В примере включён запасной вариант на случай отказа модели (`fallbacks: "default"`) — он нужен
для Opus 5.5 и Sonnet 5.5. Если выберешь Haiku 5.5, строки `betas` и `fallbacks` нужно убрать:
у Haiku такого механизма нет.

В приложении кнопка «Подсказка» будет делать `fetch` на адрес Worker'а с заголовком `x-app-token`
и показывать ответ под задачей. Если сети нет — кнопка просто неактивна.
