# Напоминания на iPhone: что реально работает

Коротко: **сайт сам по себе не может присылать уведомления, когда он закрыт.** Чтобы iPhone
«пикнул» в нужное время, кто-то должен это время помнить: либо календарь телефона, либо сервер.

## Сравнение

| Вариант | Работает на iPhone | Нужен сервер | Надёжность | Цена | Минусы |
|---|---|---|---|---|---|
| Подсказки внутри приложения (таймер, чек-ины) | только пока приложение открыто | нет | — | 0 | не будит |
| **Календарь iPhone: файл .ics с будильниками** | да, системные напоминания календаря | нет | высокая | 0 | после пересборки плана файл нужно открыть заново; повторный импорт может создать дубли |
| Web Push для сайта на экране «Домой» | да, iOS 16.4+, только для сайта, добавленного на экран «Домой», и после разрешения уведомлений | да: сервер по расписанию шлёт push, хранит подписку и твой план | средняя (iOS может задерживать) | 0 на бесплатных тарифах | самый сложный в настройке |
| **Telegram-бот** | да, обычные сообщения Telegram | да: маленький сервер с расписанием | высокая | 0 на бесплатных тарифах | бот должен знать твой план — данные уходят на сервер |
| Подписка на календарь (webcal://) | да, календарь обновляется сам | да: сервер отдаёт .ics по ссылке | высокая | 0 | тот же сервер и синхронизация, что и у бота |

## Рекомендация

**Этап 1 — сейчас, без сервера.**
1. Добавь «Рамки» на экран «Домой»: Safari → «Поделиться» → «На экран „Домой“». Так приложение
   открывается как обычное, работает без интернета и меньше рискует потерять данные.
2. Раз в неделю (в воскресенье, вместе с планом недели): «Настройки → Напоминания → Файл календаря
   на 7 дней» → «Добавить все». Удобно импортировать в отдельный календарь «Учёба»: при обновлении
   его можно удалить целиком и импортировать заново — без дублей.
3. Что уходит в календарь, зависит от строгости:
   - **мягко** — только дедлайны (напоминание накануне в 18:00 и за 3 дня для КР, лаб, зачётов);
   - **средне** — плюс напоминание к началу каждого учебного блока;
   - **строго** — плюс за 5 минут до блока, утренний и вечерний чек-ин.
   Тихие часы соблюдаются сами: на парах, в игре, в утренней электричке и во сне учебных блоков
   нет, значит, и будильников нет.

**Этап 2 — Telegram-бот (когда захочется надёжнее и без ручного обновления).**

```
«Рамки» → кнопка «Отправить план боту» → Cloudflare Worker (хранит план в KV)
                                              │ каждые 5 минут (Cron Trigger)
                                              ▼
                                   Telegram Bot API → сообщение в Telegram
```

- Создать бота у @BotFather, получить токен.
- Worker хранит токен как секрет, план недели — в KV (только названия блоков и время).
- По расписанию Worker смотрит, какой блок начинается, и шлёт сообщение `sendMessage`,
  не тревожа в тихие часы.
- Вечером бот присылает чек-ин с кнопками «Всё сделал / Часть / Не вышло»; ответ сохраняется
  в KV, приложение забирает его при открытии.
- Плюс: напоминания не зависят от того, открыт ли сайт и обновлён ли календарь.
  Минус: план хранится на сервере Cloudflare — это стоит понимать.

Бесплатного тарифа Cloudflare (Workers, Cron Triggers, KV) одному человеку хватает с запасом;
актуальные лимиты — на сайте Cloudflare.
